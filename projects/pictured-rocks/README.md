# Exploring Pictured Rocks, Michigan

A responsive multi-page tourism website developed by **Abul Shordar** as a Net-Centric Computing course project. The site introduces Pictured Rocks National Lakeshore and highlights Chapel Rock, Miners Castle, and Miners Beach.

## Live demo

[View the project on GitHub Pages](https://shordarabul.github.io/Portfolio/projects/pictured-rocks/)

## Features

- Multi-page semantic HTML structure
- Responsive layouts for desktop and mobile screens
- Custom CSS navigation, banner, content, and image styling
- JavaScript enhancement with safe DOM event handling
- Optimized WebP imagery for faster GitHub Pages loading
- Accessible image descriptions and clear navigation

## Technologies

`HTML5` `CSS3` `JavaScript` `Responsive Design` `GitHub Pages`
